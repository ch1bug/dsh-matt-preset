# batch-state —— 批次状态文件的形状（单一事实源）

本文件是 `.scratch/batch-state.md`**形状的唯一事实源**：模板、必需字段、落盘契约都写在这里。
工作流正文（`workflow-body.txt` 的 `@@ batch-mode` 节）、enforcer 的提醒文案与断言用例
**只留指针、不复述字段**——字段要改，先改这里，再让指针面跟上（D27 低频变更；量表未变不改机制，D29）。

**载体归属**：批次机制（触发、路径、命名、marker、状态行）必须落在**仓内**——`~/.dsh/skills/`
是机器本地、不随 clone 分发（#71 设计点 7）。本文件即那份仓内载体。

## 模板

批次宣告时把下面这份骨架复制成 `.scratch/batch-state.md`（`.scratch/` 是 gitignored 工作区，
不进仓、不随 clone 分发）：

```markdown
# Batch state — <批次名>

- **宣告**：<日期 / 来源指令>；批次意图：<一句话，为什么这批值得攒>。
- **成员**：<票号列表，含顺序>；**结束点**：<最后一票的票号 + 收束判据>。
- **模式**：批次内逐票本地提交 + 本地验证，不单独 push；批末一次 push。

## 成员与顺序

| # | 票 | 状态 | 说明 |
| --- | --- | --- | --- |
| 1 | #<票号> | <状态> | lane=<泳道>；后继票=#<票号> |
| 2 | #<票号> | <状态> | lane=<泳道>；后继票=#<票号> |

## 结束点

<批次收束的判据：全部完成 + 每票本地验证绿 + 未推送清单 → 批末总结 → human 确认 → 一次 push>

## 进度日志（每票结束更新）

- <日期>：**#<票号> 实现完成** → 本地提交 `<sha>`（**未 push**）。
  Progress 行三要素（证明命令 / exit code / 证据路径）：`<证明命令>` → exit `<code>` → `<证据路径>`。
  未推送清单：`<sha>` …（<N> 票）。

retro: done @ <commit>
```

`retro:` 那一行**不是模板的可选装饰**：它是批末 retro 的**完成标记**，enforcer 读它来判断
「这批的批末 retro 是否已经跑过」（`RETRO_TRIGGER.retroMarker`，存在性判据——不解析表格、
不校验其它字段）。**写这一行的是 agent**（正文规则，见 `workflow-body.txt` 的 `@@ batch-mode` 节）：
enforcer 是 reminder-only，**只读标记、不写文件**。

⚠ **两个标记、两件事**（勿混）：`retro:` 说的是「批末 retro 已**跑**」，而它写在批末 push
**之前**——所以**它单独并不能**把聚合呈现限制到每批一次（跨会话会重复聚合，实测 3 会话 → 3 次）。
真正抑制重复**呈现**的是**第二个**存在性标记 **`.scratch/retro/.aggregated`**
（`RETRO_TRIGGER.aggregatedMarker`）：agent 在**真的呈现过**聚合之后写它。已聚合批次的后续会话
**不再聚合、不再重复呈现**，但**仍跑本会话 retro 并落盘自己的候选**——每批至多一次约束的是
**呈现**，绝不是素材（**不静默丢素材**）。两个标记都由 agent 写、enforcer 只读；`.aggregated`
是 retro 素材目录里的 dot-file，与候选文件同生命周期（叫 `.md` 会被聚合自己的 `read every
.scratch/retro/*.md` 误当候选读走）。

## 必需字段

| 字段 | 判据 | 缺席的后果 |
| --- | --- | --- |
| **成员** | 宣告成员与顺序（票号 + 次序），与批次宣告逐字一致 | 无法判断「还有谁」——AUTO-HANDOFF 没有依据（D33） |
| **结束点** | 最后一票 + 收束判据 | 批次不知道什么时候停；防堆积护栏 (c) 失效（D31） |
| **Progress 行三要素** | **证明命令 + exit code + 证据路径**（测试输出本身算证据，不需另立文件） | 缺任一要素的行是 **BLOCKED，不是 done**——这是「已验」与「以为已验」的边界 |
| **lane 标注** | 该票跑在哪条泳道（A / B / C 或沙箱车道） | 批末无法回收泳道准确率（D38） |
| **后继票** | 本票之后是谁（批内顺序固定，宣告即指派） | 收尾会话只能停等 human 说「开下一票」——AUTO-HANDOFF 的路由断了 |
| **`retro: done @ <commit>`** | 批末 retro 已**跑**、commit 为聚合呈现的依据点 | 无法判断批末 retro 是否跑过；重复**呈现**的真正抑制靠 `.scratch/retro/.aggregated`（见上） |

**恢复时以本文件为唯一事实源**，不与记忆或环境「凭感觉对齐」：文件缺失、过期或与观测到的
环境（git HEAD / worktree / 文件态）矛盾 → **停下问 human**，不猜、不自行修正记录（D39）。

## 落盘契约（retro 候选）

- **位置与命名**：`.scratch/retro/<batch>-<session>.md`——一批一目录前缀、一会话一文件，
  同批可枚举、跨会话可读。
- **内容**：候选（按严重度排序）+ **证据（命令 / 输出）** + 来源（**会话 id / 票号**）
  + 未落地原因。**只写候选、不落地**——落地仍需 human 拍板（D22 / D27）。
- **只写候选不是外部动作**：写本地候选文件不触外部动作门（D21 只管 push / 关票 / 建 issue），
  所以**免确认、不阻断**收尾——会话继续，不需要停下来等确认。
- **幂等**：同会话重跑**覆盖同名文件**，不追加、不产生副本。
- **批末聚合**：先跑**本会话**一次 retro，再读齐同批已落盘的文件 → **去重合并**（同一问题在
  多个会话重复出现要合并并记次数——这正是聚合的价值）→ 按严重度排序 → **一次呈现**给 human，
  每条标注来源票号 / 会话。批末不再完整重读同批历史会话（省掉重复重读）。
- **每批至多一次**：**呈现**由 `.scratch/retro/.aggregated` 抑制（跨会话，agent 在呈现后写）；
  `retro:` 只表示批末 retro 已跑，不作呈现抑制。批内**落盘**每票一次（幂等覆盖），已聚合批次的
  后续会话照样落盘——约束呈现，不约束素材。
- **不静默丢素材**：收尾用**事实探测**（`git log origin/<branch>..HEAD` / `git status -sb`）判「已推」；
  探测到「已推但无落盘」→ 补跑或记 marker，绝不静默丢。

## 触发面（正文与 enforcer 共用的口径）

**只有真的 push 调用**触发 retro——判定输入恒为 `(toolName, argv)`（工具层 + 命令层）。
会话 / 思考 / 文档里出现「推送 / push」**字词**一律**不触发**（本仓 handoff 正文即反例）。
间接 push（经脚本）与 PTY 分片写入**一律不触发**，交事实探测兜底（**宁严勿宽**：误触发白跑一次
retro + 垃圾候选污染批末聚合，比漏一次更贵）。判定面逐字口径见 `docs/workflow-enforcer.md`。
